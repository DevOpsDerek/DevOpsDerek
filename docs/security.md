# Security

## Security model

- Governance and sensitive paths are protected through repository policy and Code Owners.
- Agentic workflows are assistive; they do not bypass review and approval controls.
- Public portfolio standards prohibit secrets, confidential data, and tenant-specific production detail.

## Guardrails

- Human review is required for governance, automation, and infrastructure-sensitive changes.
- Least-privilege and protected-environment principles apply to any future deployment workflow.
- Live Azure deployment is intentionally out of scope for this repository today.
